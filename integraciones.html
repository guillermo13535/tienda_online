Integraciones con servicios externos

Demostración de consumo de APIs reales (REST/SOAP), pasarela de pago, geolocalización, clima, datos públicos y webhooks.

💳 Pasarela de pago — Mercado Pago

Integración con Mercado Pago (Checkout Pro). El backend crea la preferencia de pago de forma segura con el Access Token.

Monto de ejemplo: $19.990 CLP

📍 Georreferenciación

Geolocation API del navegador + Nominatim (OpenStreetMap) + mapa Leaflet.

🌤️ Clima — Open-Meteo

API REST de clima en tiempo real según tu ubicación (o Santiago por defecto).

📊 Datos públicos — Banco Central (mindicador.cl)

Indicadores económicos oficiales de Chile (dólar, UF, UTM, IPC).

🔗 Webhook — Integración por POST

Envía datos a un sistema externo mediante una petición HTTP POST.

🧼 Servicio SOAP — NumberConversion

Consume un servicio SOAP (XML) que convierte un número en palabras.
